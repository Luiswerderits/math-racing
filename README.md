# MATH RACING

Projeto de jogo multiplayer de corrida matemática para uso em sala de aula.

## Tecnologias
- Vite + JavaScript
- Phaser 3
- Firebase Realtime Database
- GitHub Pages

## Estado atual
Estrutura inicial do projeto. A interface inicial está preparada; a lógica de salas, multiplayer e corrida será implementada nas próximas etapas.

## Executar localmente
```bash
npm install
npm run dev
```

## Publicação
O deploy é feito pelo GitHub Actions para GitHub Pages após push na branch `main`.
